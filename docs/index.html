That's the whole app. A number in your menu bar and a panel when you want more. It refreshes every five minutes and stays out of the way.

Small on purpose.

01

Native AppKit

A single small binary. No Electron, no web views, no helper daemons. It idles in the background using close to nothing.

02

Keychain, not plaintext

Your Polestar password is stored in the macOS Keychain, encrypted at rest. It never touches a preferences file.

03

Official API only

Polaris speaks OAuth2 with PKCE directly to Polestar's own endpoints. No third-party servers, no analytics, no telemetry — the source is short enough to read over coffee.

04

Open source

MIT licensed on GitHub. Releases are built in public by CI, straight from the tagged source.

Build it yourself.

Nothing but the Xcode Command Line Tools required. Four lines from clone to running app.

# macOS 13+, xcode-select --install
git clone https://github.com/simonbusborg/polaris
cd polaris
make app
open Polaris.app
