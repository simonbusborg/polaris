Why Polaris

Small. Native. Yours.

Glanceable state of charge

Battery %, range, charging status and time-to-full. You choose what the menu bar shows.

Charging notifications

A quiet nudge when charging starts, completes, or the charger reports a fault. Nothing else, ever.

Keychain, not plaintext

Password and session live in the macOS Keychain. Once signed in, Polaris resumes its session without logging in again.

Official API only

OAuth2/OIDC with PKCE against Polestar's own endpoints. No third-party servers, no analytics, no tracking.

Stays current

A once-a-day check against GitHub releases; when there's a new version, a menu item appears. No background updater.

Open source

MIT licensed, pure AppKit, no Electron, no SwiftUI, no background services. make app and you have it.

The studio render of your exact configuration — paint, wheels and all —
fetched straight from Polestar and shown at the top of the menu.

Get started

Running in a minute.

No terminal, no Xcode — every release is a ready-built app. Download, drag to Applications and sign in with your Polestar account. Your VIN is in the Polestar app if it's not on hand.

Prefer to compile it yourself? Build from source is one command.

  1. Download Polaris.dmg and open it
  2. Drag Polaris into the Applications folder
  3. Open it — no security warning to click past. Polaris is signed with a Developer ID and notarized by Apple.
  4. Sign in — email, password, VIN
